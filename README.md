## Featured project

### [Digital Equb — Android](https://github.com/jolly26/DigitalEqub_android)

A local-first Android app for managing **Equb (እቁብ)**, Ethiopia’s rotating savings tradition. It helps organizers track group contributions and supports transparency between members.

- Works offline, keeping group records on device.
- Tracks members, contribution cycles, partial payments, and payment history.
- Supports organizer and co-organizer roles, audit logs, and reviewable data sync.
- Parses transaction alerts from Ethiopian payment providers to help record payments.
- Built with **Kotlin, Jetpack Compose, Room, Coroutines, and Flow**.
